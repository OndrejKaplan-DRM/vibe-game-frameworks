# Karta projektu — arkáda „Dinosaurus“ (zkušební hra Shellu)

1. **Jádro hry jednou větou:** běžím, skočím ve správnou chvíli a ono to cinkne.
2. **Co hra není:** plošinovka s levely; hra s příběhem; hra s účty a žebříčky na síti.
3. **Publikum a zařízení:** děti i dospělí; notebook s integrovanou grafikou, telefon, tablet.
4. **Referenční slabý stroj:** zatím neurčen (návrh: Lenovo T460). Měření v této iteraci jsou jen ze sandboxu bez grafické karty.
5. **Distribuce:** jeden soubor `dist/arkada.html`; později GitHub Pages.
6. **Varianta:** A (web, Canvas 2D, bez enginu). Malý rozsah, sdílení souborem, testy bez prohlížeče.
7. **Tón:** dětský (`kid`). Rozhraní zatím obsahuje text; verze pro předčtenáře je úkol milníku M4.
8. **Zdroje dat a assetů:** žádné cizí. Grafika jsou obdélníky, zvuk se syntetizuje.
9. **Rozpočty:** krok ≤ 2 ms, start do menu ≤ 5 s, soubor zdrojového kódu ≤ 600 řádků, sestavený soubor ≤ 200 kB.
10. **První hratelný milník:** M1 (tato iterace, 19. 11. 2026).

Účel projektu navíc: prověřit sadu Level 1 a postavit na něm Shell po krocích S0–S4.
